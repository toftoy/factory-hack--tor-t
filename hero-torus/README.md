# Torus Hero

Hero-seksjon i ren HTML/CSS med Three.js-bakgrunn (three@0.169.0 fra jsDelivr):
langsomt roterende glass-torus (`MeshPhysicalMaterial` med transmission, dispersjon,
clearcoat), fysisk lys og et generert studio-miljøkart (PMREM) med varme og kalde
lyspaneler. Bakgrunnen er en tåke-shader i marineblått og oransje som glasset bryter.

Åpne `index.html` direkte i en nettleser. Respekterer `prefers-reduced-motion`.

`process/` har skjermbilder fra hver iterasjon (r0 = start, r1–r7 = forbedringsrunder; `-t20` = etter 20 s rotasjon),
desktop 1440×900 og mobil 390×844.
